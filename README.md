# 文書管理システム

規程・手順書・様式・図面・契約書などの文書全般について、**版管理・確認/承認・周知・教育記録・見直し期限・設備台帳・監査出力**を行う社内向けWebアプリ。
設計は `docs/設計書.md` を参照。Python 3.12 / FastAPI / SQLite。

> **このリポジトリは公開の場合があります。実際の文書(PDF)・DB・パスワード・シークレットは絶対にコミットしないこと**
> (`data/`、`*.db`、`.env` は `.gitignore` 済み)。データは社内の保存先(`DOCMGMT_DATA`)にだけ置く。

## 起動
```
python -m venv .venv
.venv/bin/pip install -r requirements.txt           # Windows: .venv\Scripts\pip
export DOCMGMT_SECRET="ランダムな長い文字列"         # 必須(未設定だと起動しない)
export DOCMGMT_DATA=/path/to/data                   # 社内の保存先(GitHub管理外)
export DOCMGMT_HTTPS=1                              # HTTPSで運用する場合
.venv/bin/python -m scripts.create_admin            # 最初の管理者を作成
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```
起動後、ブラウザで http://localhost:8000 を開きます。

### デモで画面を試す(実データ不可)

## 機能
| 区分 | 内容 |
|---|---|
| アカウント | 作成・無効化・役割変更・パスワード再設定・ロック解除。初回ログイン時にパスワード変更を強制。5回失敗で15分ロック |
| 役割 | 管理者 / 申請者 / 確認者 / 承認者 / 閲覧者 |
| 申請 | 下書き作成→編集→確認依頼。改訂内容・改訂理由・適用開始日が必須。PDFのSHA-256を記録 |
| 承認フロー | 申請者 →(確認者)→(承認者)。差戻しは下書きに戻り、経過とコメントが残る。取下げ可 |
| 職務分離 | 自分の申請は確認・承認できない。確認者は同じ版を承認できない。管理者は承認できない |
| 版管理 | 承認後は内容固定(DBトリガー)。新版の適用開始で旧版は自動で廃版。上書き・削除不可 |
| 閲覧制御 | 閲覧者には適用中の最新版のみ表示。旧版・未承認版は担当者のみ |
| 検索 | 文書番号・名称・分類・部署・改訂内容、廃止文書の表示 |
| 定期見直し | 見直し周期から期限を計算し、超過・間近を表示。見直し結果を記録 |
| 周知・教育 | 版ごとの周知確認(本人が記録)、教育実施記録(実施日・講師・受講者) |
| 設備台帳 | 測定器・保護具・検査機器等。使用開始日、校正記録・期限、文書との紐付け |
| 関連文書 | 文書どうし(規程↔手順書↔様式など)のリンク |
| 文書の廃止 | 理由必須。管理者のみ取消可 |
| 整合性チェック | 遡及適用、教育未実施/適用開始後の教育、未周知、見直し超過、校正超過、滞留、PDF改ざん、ログ改ざん |
| 監査出力 | 文書台帳・改訂履歴・承認記録・周知確認・教育記録・設備台帳・操作ログをExcel/CSVで出力(数式インジェクション対策済み) |
| 操作ログ | 追記のみ+ハッシュ連鎖で改ざん検知。閲覧・出力も記録 |

## 運用スクリプト
```
python -m scripts.backup [出力先]   # DBとPDFをzipで保存(稼働中でも可)。別機器・別拠点にも保管し、復元テストを記録する
python -m scripts.verify           # 操作ログの連鎖とPDFハッシュを検証(定期実行推奨)
```

## テスト
